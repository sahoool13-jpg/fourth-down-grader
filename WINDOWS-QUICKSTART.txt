4TH DOWN v0.2 - WINDOWS QUICK START
==================================

1. Make sure this folder has been extracted from the ZIP.
2. Double-click: start-windows.bat
3. Leave the black command window open.
4. Your browser should open http://localhost:3000 automatically.

If Windows says Node.js is missing:
- Install Node.js 20 or newer from nodejs.org
- Then double-click start-windows.bat again.

TO STOP THE APP
Close the black command window.

TO PUT IT ONLINE
Open ONLINE-DEPLOY.txt and follow the GitHub + Render steps.
