4TH DOWN v0.3 - PUT IT ONLINE WITH RENDER
=========================================

Your existing Render service can keep using the same public URL.

UPDATE AN EXISTING INSTALL
1. Extract this v0.3 ZIP.
2. Copy everything inside it into your cloned GitHub folder:
   Documents > GitHub > fourth-down-grader
3. Do NOT delete the .git folder in the cloned repo.
4. Replace existing files when Windows asks.
5. In GitHub Desktop, commit to main and Push origin.
6. Render is connected through the public-repository URL route, so go to the Render service and choose:
   Manual Deploy > Deploy latest commit
7. Hard refresh the website with Ctrl + Shift + R.

NEW IN v0.3: NFL4TH VALIDATION
- The repo now includes .github/workflows/nfl4th-benchmark.yml and scripts/run_nfl4th_benchmark.R.
- A push to main triggers the benchmark workflow for 2026_03_ATL_GB by default.
- The workflow computes exact nfl4th::add_4th_probs() results and commits a JSON file under public/benchmarks/.
- The live app fetches that benchmark directly from GitHub, so the benchmark can appear without another Render deploy.

IF THE BENCHMARK WORKFLOW CANNOT COMMIT
GitHub > repository Settings > Actions > General > Workflow permissions
Choose: Read and write permissions
Then rerun the "nfl4th benchmark" workflow.

BENCHMARK ANOTHER GAME
GitHub > Actions > nfl4th benchmark > Run workflow
Enter an nflverse game ID such as:
2026_03_ATL_GB

FREE RENDER NOTE
Free services may spin down after inactivity, so the first visit after a quiet period can take longer to load.
