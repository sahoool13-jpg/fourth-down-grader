4TH DOWN v0.4.1 — CALIBRATION INTEGRITY

WHY THIS EXISTS
v0.4 exposed huge 97–100 pp "model errors" where nfl4th showed PUNT = 0.0%.
Those were not real 0% estimates. The R output contained NA/null for an unsupported
reference action, and JavaScript accidentally converted null to numeric zero.

v0.4.1 fixes that before any model tuning.

WHAT CHANGES
- null/NA reference options stay unavailable
- real numeric zero probabilities remain real zeros
- primary choices not priced by nfl4th become REFERENCE GAPS
- reference gaps are excluded from regret and split-rate denominators
- clean failure tape contains only comparable decisions
- separate reference-gap tape shows the excluded cases
- full 3-option coverage and primary-call coverage are displayed
- baseline WP nulls are no longer coerced to zero in historical replay
- historical-calibration workflow verifies the integrity separation
- 10 dedicated calibration-integrity tests pass locally

INSTALL
1. Extract this ZIP.
2. Copy everything inside into Documents > GitHub > fourth-down-grader.
3. Replace matching files. Keep the .git folder untouched.
4. GitHub Desktop Summary:
   Fix calibration reference integrity v0.4.1
5. Commit to main, then Push origin.
6. GitHub Actions > historical calibration will rerun automatically.
7. Let it finish. It should take roughly the same few minutes as v0.4.
8. Render > Manual Deploy > Deploy latest commit (needed for the new dashboard code).
9. Hard refresh with Ctrl+Shift+R.

EXPECTED RESULT
The top pathological 99.98 pp punt rows should disappear from the CLEAN FAILURE TAPE.
If the primary model chooses an action nfl4th did not price, it will appear in REFERENCE GAPS
with no fake regret number.
